### Goal

Create the database structure and CRUD operations needed to manage factors and constants.

This includes both emission factors and calculation constants such as GWP, PCI/LHV, density, carbon fraction, root-to-shoot ratio, and conversion constants.

### Acceptance criteria

- [ ] Factors table/model exists
- [ ] Constants table/model exists
- [ ] Required fields from the architecture are implemented
- [ ] Factor can be created
- [ ] Factor can be read/listed
- [ ] Factor can be updated
- [ ] Factor can be deleted
- [ ] Constant can be created
- [ ] Constant can be read/listed
- [ ] Constant can be updated
- [ ] Constant can be deleted
- [ ] Migrations run successfully
- [ ] At least one real factor and one real constant can be stored
