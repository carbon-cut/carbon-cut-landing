# Build inventory validation from project context

Create the GHG emissions inventory schema from the Project's inventory boundary and setup applicability. The registry derives dataset eligibility from those inputs for both the workspace and schema builder. The top-level builder combines schema parts; a part owns any field rule that varies with those inputs, while static parts keep their existing schemas. Validate activity data within the boundary and applicable to the Project; keep saved activity data outside the boundary in drafts without validating it. Shared data is required for both boundaries: the whole-territory boundary retains its existing field rules, while the municipal-assets boundary requires population and does not validate territory-only fields such as the household-energy consumption norm. Purchased Services may later make other fields required, independently of the inventory boundary; Service rules are not part of this change.
